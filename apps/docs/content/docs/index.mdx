## Material 3 is the normative design source

Material Design 3 defines the design intent. AndroidX Compose Material3 provides current Material API vocabulary and implementation evidence. Browser semantics and React Aria Components provide the web interaction and accessibility mapping. The `m3-ui` public implementation is the API that consumers can actually import today.

That hierarchy means a correct web adaptation is not automatically a parity failure, and an implementation detail from Compose is not automatically a public React API requirement. These docs call out adaptations and known gaps explicitly rather than claiming complete Material parity globally.

## Documentation boundary

Public docs are curated developer guidance. Storybook remains the exhaustive component visual-review and regression surface. Fumadocs supplies the content/page-tree/search pipeline, while the visible documentation product is rendered with `m3-ui` itself.
