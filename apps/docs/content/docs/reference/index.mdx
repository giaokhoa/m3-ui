Reference pages answer evidence and inventory questions rather than teaching one application workflow.

- [Parity catalog](/docs/reference/parity) is the data-driven index of Material provenance, fidelity dimensions, intentional adaptations, and known gaps for documented components.

Use [Get started](/docs/getting-started) for onboarding and project contracts, [Foundations](/docs/foundations) for shared Material systems, [Develop](/docs/develop) for cross-component application guidance, and [Components](/docs/components) for individual component usage.

## Source-of-truth boundary

Reference surfaces consume the same generated provenance and public implementation data as the rest of the documentation. They do not maintain a second component inventory, redefine canonical token values, or turn implementation evidence into a separate public API.
