Radio buttons let users select exactly one value from a mutually exclusive set. Group related options with `RadioGroup` so selection, labeling, validation, and keyboard behavior share one semantic boundary.

[Material 3 radio button](https://m3.material.io/components/radio-button/overview)

<ComponentPreview>

</ComponentPreview>

```tsx
import { RadioButton, RadioGroup } from '@m3-ui/ui';

<RadioGroup name="density" defaultValue="standard" label="Density">
  <RadioButton value="compact">Compact</RadioButton>
  <RadioButton value="standard">Standard</RadioButton>
  <RadioButton value="comfortable">Comfortable</RadioButton>
</RadioGroup>
```

## When to use

Use radio buttons when the user must choose one option from a visible set. Use checkboxes for independent choices and segmented single-choice controls when the compact connected Material presentation is more appropriate.

## Group contract

`RadioGroup` owns the selected value and shared label, plus optional description and error text. It inherits React Aria value, validation, form, and event props rather than introducing a separate selection model.

The default vertical arrangement works for most sets. `orientation="horizontal"` is a layout choice for suitable short option sets; it does not define a new Material radio family.

## Behavior and states

React Aria owns radio-group/radio semantics, arrow-key focus/selection behavior, disabled state, controlled/uncontrolled values, and form participation. Material tokens own the control geometry, selected dot, colors, ripple/state indication, and interaction target.

Keep every option in its logical `RadioGroup` so the browser exposes the one-of-many relationship correctly.

## Accessibility

The group needs a meaningful shared label or accessible name, while each `RadioButton` needs an option label. Description/error text should describe the group or option state rather than relying on color alone.

Keyboard behavior follows the radio-group model; do not attach custom arrow-key handling that competes with React Aria selection/focus management.
