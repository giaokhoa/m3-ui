Progress indicators communicate the status of an ongoing process. Use determinate progress when completion can be measured and indeterminate progress when it cannot.

[Material 3 progress indicators](https://m3.material.io/components/progress-indicators/overview)

```tsx
import {
  CircularProgressIndicator,
  LinearProgressIndicator,
} from '@m3-ui/ui';

<LinearProgressIndicator aria-label="Upload progress" value={0.64} />
<CircularProgressIndicator aria-label="Loading" isIndeterminate />
```

## Families

The public baseline family contains `LinearProgressIndicator` and `CircularProgressIndicator`. `LinearWavyProgressIndicator` and `CircularWavyProgressIndicator` expose the audited M3 Expressive waveform family.

Choose the family that matches the product's Material language; do not use decorative progress motion when no process is actually being communicated.

## Determinate and indeterminate

Pass `value` for known progress or `isIndeterminate` when completion cannot be estimated. The component delegates progress range/value semantics to React Aria while Material owns the visual track/indicator geometry and motion.

The rendered visual drawing is hidden from accessibility so SVG/path implementation details are not announced as duplicate content.

## Expressive waveform

Wavy indicators preserve the audited waveform/amplitude/motion behavior. Renderer controls such as amplitude/wavelength/speed are implementation controls, not a new set of normative Material design tokens.

Reduced-motion preference removes or freezes motion while preserving a valid progress visual and unchanged progressbar semantics.

## Web compatibility adaptations

`bufferValue` on standard linear progress and `fourColor` on standard indeterminate indicators are audited Material Web compatibility surfaces. They remain explicitly classified as adaptations rather than generalized to every Material/Compose progress family.

## Accessibility

Every standalone indicator needs an accessible label via `aria-label` or `aria-labelledby` because the Material visual does not render a visible label. For determinate progress, let React Aria expose the current numeric value/range rather than duplicating it in the SVG.

Do not move focus to a progress indicator merely because progress changes. Use surrounding status messaging when a process needs additional announcement.
