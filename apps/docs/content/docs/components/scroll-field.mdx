`ScrollField` is a compact wheel-style selector for ordered values such as hours, minutes, quantities, or units. The visual wheel maps to one browser value-adjustable control rather than exposing every repeated slot as an independent option.

</ComponentPreview>

```tsx
import { ScrollField } from '@m3-ui/ui';

<ScrollField
  aria-label="Minutes"
  items={['00', '15', '30', '45']}
  selectedIndex={selectedIndex}
  onSelectionChange={setSelectedIndex}
/>
```

## When to use

Use a scroll field for a compact ordered sequence where incremental wheel-style adjustment supports the task. Prefer radio/segmented controls for a small categorical set and a text/number field when exact typed entry is more efficient.

## Selection state

Use `items` for a simple finite list or `itemCount` with `renderItem` for generated/richer content. Controlled `selectedIndex` or uncontrolled defaults represent the single current value.

`getItemText` supplies meaningful accessible value text when the rendered React content is not a useful plain string.

## Input behavior

Arrow Up/Down, wheel interaction, pointer dragging, and direct visible-item activation update the same selected index. `isDisabled` disables adjustment while preserving the current value semantics. Reduced-motion preference removes unnecessary smooth movement without changing selection.

## Spinbutton semantics

The root exposes one `spinbutton` with a numeric range based on item indices and `aria-valuetext` for the human-readable selected item. This intentionally differs from exposing every decorative/repeated visual slot as a separate selectable control.

## Local measurement

The component measures its own rendered height to position wheel slots. This is local presentation geometry only and is unrelated to Material window-size classes, pane directives, or application responsive policy.

## Accessibility

Provide a meaningful accessible label identifying what value the wheel controls. Ensure `getItemText` returns understandable value text for non-text content. Do not add a second keyboard-adjustment model around the spinbutton.
