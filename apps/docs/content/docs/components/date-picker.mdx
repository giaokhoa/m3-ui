## Overview

`DatePicker` and `DateRangePicker` implement the Material date-selection surfaces for a single Gregorian calendar date or an inclusive date range. Both support controlled or uncontrolled values, calendar navigation, year selection, unavailable dates, locale-aware presentation, and an optional text-input mode.

## Date-only state

The public state is intentionally timezone-free:

```tsx
const [date, setDate] = useState<DatePickerDate | null>('2026-08-29');

<DatePicker value={date} onChange={setDate} />
```

`DatePickerDate` is an ISO calendar-date string such as `2026-08-29`. Selection state never becomes a JavaScript `Date`; UTC is used only internally as an `Intl.DateTimeFormat` transport when formatting a date for a locale.

Helpers such as `isDatePickerDate`, `compareDatePickerDates`, `monthStart`, and `formatDatePickerDate` expose the same date-only contract to applications.

## Single and range selection

Use `DatePicker` for one date and `DateRangePicker` for `{ start, end }` state. Range input rejects an end date before its start date. `isDateUnavailable` keeps a calendar date focusable while preventing selection, and `yearRange` constrains both calendar and segmented input modes.

## Calendar and input modes

The default `calendar` mode uses React Aria `Calendar` or `RangeCalendar` semantics. The optional `input` mode uses React Aria `DateField`, `DateInput`, and `DateSegment` primitives while preserving the same ISO date-only application state.

React Aria owns segment ordering, keyboard editing, focus movement, placeholder state, and field validation. Material styling is applied to the field surface and segment interaction states instead of relying on the browser-specific UI of native `input type="date"` controls.

`locale` controls month, weekday, headline, and date-segment presentation. `firstDayOfWeek` can override the locale default when the product has an explicit calendar convention.

## Modal versus docked

`variant="modal"` selects the Material modal-picker **surface style**. It does not create an overlay, focus trap, scrim, or dialog lifecycle by itself. Compose it with the public `Dialog` primitives when the picker should be modal.

```tsx
<DialogTrigger>
  <Button>Choose date</Button>
  <DialogOverlay>
    <Dialog aria-label="Choose date">
      <DatePicker />
    </Dialog>
  </DialogOverlay>
</DialogTrigger>
```

`variant="docked"` keeps the calendar presentation docked and intentionally disables the calendar/input mode toggle.

## Validation and errors

Manual input uses React Aria field validation for year bounds and unavailable dates. In range mode, incomplete or reversed drafts are kept local and do not publish a corrupt public range value. Pass `errorMessage` for application-facing validation copy.
