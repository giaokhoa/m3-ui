Toggle buttons are button-shaped controls with persistent selected state. Use them when pressing the control changes an on/off choice that remains visible after activation; use an ordinary button when the action is momentary.

```tsx
import { FilledTonalToggleButton } from '@m3-ui/ui';

const [selected, setSelected] = useState(false);

<FilledTonalToggleButton
  isSelected={selected}
  onChange={setSelected}
>
  Pin
</FilledTonalToggleButton>
```

## When to use

Use a toggle button for persistent toolbar-like or action-like selection such as pinning or enabling a mode. For independent form choices, prefer Checkbox or Switch according to the Material interaction model. For a mutually exclusive set of adjacent choices, use the appropriate segmented/connected selection component.

## Variants

The public family exposes `ToggleButton`, `ElevatedToggleButton`, `FilledTonalToggleButton`, and `OutlinedToggleButton`. Choose the visual variant from action hierarchy while keeping selection semantics unchanged.

## Controlled selection

Selection is explicit application state through `isSelected` and `onChange`. The component does not maintain a competing selected-state machine, so the rendered Material state always follows the current controlled value.

Do not use `isSelected` merely to force a pressed-looking style after a normal action. It represents persistent selection.

## Sizes and icons

All variants support the audited Material expressive size vocabulary: `extraSmall`, `small`, `medium`, `large`, and `extraLarge`. `startIcon` participates in the component's canonical icon/spacing geometry.

Choose a semantic size rather than reproducing token dimensions in consumer CSS.

## Behavior and states

Checked, unchecked, pressed, hovered, focused, and disabled presentation comes from the component token/runtime mapping. Selected and pressed shape transitions follow the audited renderer path; reduced-motion preference removes transition timing without changing the controlled final state.

## Accessibility

On the web, `m3-ui` intentionally uses React Aria `ToggleButton`, which exposes native button interaction with `aria-pressed`. This differs from Compose's runtime projection while preserving the user-facing persistent toggle concept.

Browser-standard Enter/Space activation, focus-visible behavior, and disabled handling come from React Aria. Visible text should identify the toggled property or action consistently.
