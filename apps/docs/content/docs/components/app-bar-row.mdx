`AppBarRow` arranges app-bar actions on the inline axis and keeps the largest fitting prefix visible. When its own container becomes too narrow, only the non-fitting suffix moves into an overflow menu.

```tsx
import { AppBarRow, type AppBarAction } from '@m3-ui/ui';

const items: AppBarAction[] = [
  { type: 'action', id: 'share', label: 'Share', icon: <ShareIcon />, onPress: share },
  { type: 'toggle', id: 'pin', label: 'Pin', icon: <PinIcon />, isSelected: pinned, onChange: setPinned },
];

<AppBarRow aria-label="Document actions" items={items} />
```

## When to use

Use `AppBarRow` when a local app-bar/action slot must preserve important actions inline and move lower-priority suffix actions into overflow as that slot shrinks. It is not a substitute for application adaptive navigation or pane decisions.

## Item model

The public action union distinguishes ordinary actions, controlled toggles, and custom items. Built-in labels become the accessible names for both inline and overflow representations.

Custom items must provide explicit inline and overflow renderers so the application can preserve equivalent semantics in both placements. The overflow renderer receives `dismiss()` for closing the popup after an application-owned activation.

## Local overflow behavior

The row measures its own container/item widths with `ResizeObserver`. `maxItemCount` can add a slot-count constraint; whenever overflow exists, the overflow trigger itself consumes a slot.

This means a narrow panel on a large monitor can overflow while a roomy slot on a smaller window can keep all actions inline. That is expected: the policy is local geometry, not window-size classification.

## Overflow menu

The default overflow trigger is an accessible “More actions” control. A custom trigger may replace it while React Aria Menu continues to own popup positioning, keyboard navigation, dismissal, and focus restoration.

Controlled toggle state remains application-owned whether an item is currently inline or overflowed.

## Accessibility

Give the action row an accessible label when its purpose is not obvious from context. Ensure custom inline/overflow renderers expose equivalent names and state. Do not duplicate an action in both visible and overflow surfaces at the same time.
