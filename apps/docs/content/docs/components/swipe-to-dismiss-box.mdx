Swipe to dismiss reveals background content while a foreground surface moves toward a logical dismissal anchor. The component owns gesture recognition and Material settling; the application owns what dismissal means for its data model.

## When to use

Use swipe-to-dismiss where a horizontal dismissal gesture is appropriate and discoverable for the item type. Keep an explicit action or equivalent recovery path when the product requires accessible non-gesture operation or undo.

## State and dismissal ownership

The public settled values are `settled`, `start-to-end`, and `end-to-start`. Use controlled `value`/`onValueChange` or `defaultValue` for local interaction state.

`onDismiss` runs after settling at an enabled dismissal anchor. Removing an array item, persisting deletion, undo, or resetting the item to `settled` remains application logic.

## Logical directions and RTL

Start/end directions follow reading direction. RTL reverses the physical direction while preserving the same logical state values. Either logical direction can be independently disabled.

## Gesture arbitration

The pointer recognizer waits for horizontal intent and rejects vertical gestures so page/list scrolling can continue. Material threshold/velocity rules choose whether release returns to settled or advances to an enabled dismissal anchor. Reduced-motion changes animation, not the resulting state.

## Foreground interactions

The foreground remains normal content. Links, buttons, inputs, and other controls keep their own semantics and must not be flattened into one fake swipe/button surface. Background actions also remain independently named when interactive.

## Accessibility

Provide contextual naming when the dismissible region itself needs identification. A swipe gesture alone is not a good sole mechanism for critical actions; applications should expose equivalent controls or undo where required by the workflow.

Do not remove focus unexpectedly before the application has chosen where focus should move after an item is actually removed.
