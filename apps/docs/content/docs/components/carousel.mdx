## Overview

The public carousel family contains three horizontal Material arrangements:

- `HorizontalMultiBrowseCarousel` for browsing several differently masked items at once.
- `HorizontalUncontainedCarousel` for a continuous row of fixed-width items.
- `HorizontalCenteredHeroCarousel` for a dominant centered item with supporting neighbors.

All three share the same carousel state and item-render contract. The component owns Material keyline geometry and scrolling behavior; application content remains normal React content.

## State

Use `useCarouselState` when application code needs the current item or imperative navigation:

```tsx
const state = useCarouselState({
  itemCount: 8,
  defaultCurrentItem: 1,
});

<HorizontalMultiBrowseCarousel
  aria-label="Featured albums"
  preferredItemWidth={186}
  state={state}
>
  {({ index }) => <AlbumCard album={albums[index]} />}
</HorizontalMultiBrowseCarousel>
```

`scrollToItem()` moves immediately and `animateScrollToItem()` requests smooth scrolling. Smooth movement resolves to immediate scrolling when the user prefers reduced motion.

The convenience `currentItem`, `defaultCurrentItem`, and `onCurrentItemChange` props expose the same controlled/uncontrolled state model without creating a state object explicitly.

## Item geometry

A render function receives `index`, the current masked `size`, `minSize`, `maxSize`, and `isFocal`. These values describe the Material carousel geometry for that item; they are useful for content that needs to react to focal size without duplicating the keyline algorithm.

`preferredItemWidth`, `itemWidth`, `maxItemWidth`, spacing, and content padding configure the appropriate Material variant. The carousel measures its own viewport with `ResizeObserver` and recalculates local keyline geometry when that viewport changes.

That measurement is component-local. It does not define compact/medium/expanded window classes and is unrelated to `@m3-ui/ui/layout` pane behavior.

## Browser interaction and accessibility

The outer component is a named `region` with `aria-roledescription="carousel"`. Provide `aria-label` or `aria-labelledby` so the region has a useful name.

The focusable viewport supports Left/Right arrows with RTL-aware logical direction plus Home and End. Pointer dragging and native horizontal scrolling update the same current-item state.

Set `userScrollEnabled={false}` when an application needs a programmatically controlled presentation; the viewport remains visually clipped instead of accepting user scroll gestures.

## Snapping

Multi-browse and centered-hero variants settle to the Material focal item after interaction. The uncontained variant intentionally preserves its continuous row behavior instead of forcing the same focal snapping rule onto every carousel family.
